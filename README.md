# Setu

**Every request finds its way.**

Setu is a family coordination platform that transforms voice-based requests into structured, actionable tasks. Supporting Hindi, Marathi, and English, it helps families manage everyday responsibilities, track progress, and stay connected through a centralized platform.

## Overview

Setu aims to simplify family coordination by providing a centralized place to communicate requests, manage responsibilities, and track task completion.
